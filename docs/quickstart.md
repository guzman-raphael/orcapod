# Quickstart

Follow these steps to run your first Orcapod pipeline demo.  

## 1. Clone the repository

```bash
git clone https://github.com/walkerlab/orcapod
```

## 2. Switch to the pipeline branch

```bash
git checkout pipeline
```

## 3. Open in a dev container

- In VS Code, open the command palette (`Ctrl+Shift+P` on Windows or `Cmd+Shift+P` on Mac)
- Select `Dev Containers: Reopen in Container`
- Wait for the container to build and start

## 4. Run the demo notebook

- Navigate to `tests/extra/python/`
- Open `pipeline_test.ipynb`
- Run the cells to execute a sample pipeline
